# Held: poets whose work is still in copyright

Amrita Pritam, Munir Niazi, Shiv Kumar Batalvi, Surjit Patar and Ustad Daman are kept out of the site
(owner, 2026-11-17) until permission to publish is arranged. Their poet files and portraits are kept here,
outside `src/`, so no build reads them. To bring a poet back: move the file to `src/content/poets/`, the
portrait to `src/assets/portraits/`, and fix the `portrait:` path.
